LESSON 5.02 · THE PATTERN
Same endings — one vowel flips to ie
Keep everything you know about endings. Just watch the middle of the verb.
👋 THE ONE IDEA
In a boot verb, the stem vowel e changes to ie in every present form except nosotros. The endings stay exactly the same.

Take querer (to want). It's a normal -ER verb, so it uses the -ER endings you already know: -o / -es / -e / -emos / -en. The only twist is the stem: quer- becomes quier- inside the boot. That's the whole rule.

🧩 THE STEM CHANGE
Infinitive: querer → stem quer- → inside the boot: quier-

So quier- + the yo ending -o = quiero (“I want”). But nosotros stays outside the boot, so it keeps the plain stem: quer- + -emos = queremos (“we want”) — no vowel change.

📝 THE FULL BOOT · querer (to want)
Subject (who)Stem + endingFull form
yo (I)quier·oquiero
tú (you, friendly)quier·esquieres
usted / él / ellaquier·equiere
nosotros / nosotras (we)quer·emos (no change!)queremos
ustedes / ellos / ellasquier·enquieren

Four forms change (quiero, quieres, quiere, quieren) and one does not (queremos). Draw a line around the four that change and you get the boot shape — nosotros is the piece left outside. Notice we use ustedes for “you all,” the standard form across Latin America.

📝 A SECOND BOOT VERB · pensar (to think)

Pensar is an -AR verb, so it uses the -AR endings -o / -as / -a / -amos / -an. Same boot rule: pens- → piens- everywhere but nosotros.

💡 HEAR THE PATTERN · REAL SENTENCES

These ride on vocabulary you already know. Press ▶ to hear each one and say it back — listen for the ie:

Yo quiero practicar español. — I want to practice Spanish. (querer → quier- + o)
Tú piensas en español. — You think in Spanish. (pensar → piens- + as)
Nosotros queremos estudiar juntos. — We want to study together. (nosotros = NO change: quer- + emos)

Hear the difference? quiero and quieres have the ie, but queremos does not. Now drill it.

⚡ TRY IT · BOOT-VERB DRILL
Pick the correct form. Watch the subject: is it inside the boot (change to ie) or is it nosotros (no change)? Instant feedback on each.
1. Yo ____ un libro nuevo. (querer — I want a new book.)
2. Tú ____ en español. (pensar — You think in Spanish.)
3. Nosotros ____ practicar. (querer — We want to practice.)
4. Ella ____ mucho antes de hablar. (pensar — She thinks a lot before speaking.)
5. Ustedes ____ viajar en verano. (querer — You all want to travel in summer.)
⚡ TAP TO REVEAL · INFINITIVE → "YO" FORM

🔑 TODAY'S TAKEAWAY

Boot verbs keep the ordinary endings and change one stem vowel: e → ie in every form except nosotros. Chant it with querer: quiero, quieres, quiere, queremos, quieren — four with ie, one without.
