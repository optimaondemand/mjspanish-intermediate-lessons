LESSON 7.05 · PULLING IT TOGETHER
Three boot families — one single rule
You have now met every kind of boot verb. Today you see how they are all the same thing.
🔑 THE ONE RULE BEHIND ALL OF THEM
In every boot verb, the stem changes in all present forms except nosotros — which always keeps the original stem.

The endings never change. Only the stem does, and only inside the “boot.” The kind of change is the only difference between the families: e→ie, o→ue (plus jugar's u→ue), and now e→i.

🧩 WHY WE CALL IT A “BOOT”

Draw a line around the forms that change and you sketch a boot: the toe and top change, the heel — nosotros — stays outside.

5. Across all three families, which subject keeps the original stem (no change)?
🔑 TODAY'S TAKEAWAY

Three families, one rule: the stem changes in every present form except nosotros. If you can name the change (e→ie, o→ue/u→ue, e→i) and remember to leave nosotros alone, you can conjugate any boot verb you meet.
